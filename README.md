# GPX Cleaner

Веб-приложение для визуальной очистки GPX-треков.

**Репозиторий:** https://github.com/georgenaz/gpx-dot-cleaner

## Запуск

```bash
uv sync
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Открыть: **http://localhost:8000**

## Возможности

- 📂 Загрузка GPX-файла
- 🗺 Карта OpenStreetMap с двумя наложенными треками (оригинал + очищенный)
- 🔴 Выбор точек кликом
- ✅ Выбор рамкой (drag)
- ⇧ Shift + рамка — добавить к выбору
- Ctrl + рамка — снять выбор
- 🗑 Удаление выбранных точек
- ↩ Undo (отмена последних удалений)
- 💾 Экспорт очищенного GPX
